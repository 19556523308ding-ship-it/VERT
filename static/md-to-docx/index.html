Markdown 转 Word

Markdown 是一种轻量级标记语言，用纯文本写笔记、文档和说明极其高效——一个 # 就是标题，- 就是列表，但它的 .md 文件在 Microsoft Word、WPS、企业 OA 或打印装订场景中常常「打不开、排不好、同事没法编辑」。Markdown 转 Word 工具就是把你的 .md 笔记一键渲染成规范的 .docx 文档：标题、列表、表格、代码块等常见 Markdown 语法都会保留并自动套用 Word 样式，交付给用 Word 的同事、导师或客户时，不用再手动复制粘贴调格式。

三步完成转换

  1. 粘贴或上传 Markdown：把 .md 文件内容粘贴进输入框，或直接拖入文件。
  2. 点击转换：引擎在浏览器本地解析 Markdown，生成标准 .docx 文档。
  3. 下载 Word 文件：在「转换结果」区域点击下载即可，文件完全在本地完成，无需等待上传。
格式对照： Markdown 里 # 标题 会映射为 Word 的「标题 1」样式，- 列表项 生成自动编号/项目符号，| 表格 | 变成可编辑的 Word 表格，```代码``` 块则套用等宽字体并带灰色底纹——整体排版一气呵成。

为什么用本地转换？

Markdown 文档常包含私有笔记、未公开的技术方案或内部规范，上传到第三方服务器意味着内容彻底脱离你的控制，存在泄露和滥用的风险。本工具的所有转换都在浏览器本地完成，文件不上传、不存储、不留痕。首次使用需下载转换引擎（体积仅几百 KB，一次性操作），之后秒开、免费不限次，批量转换也不排队。

常见问题

Q：Markdown 转 Word 支持哪些语法？
A：支持标题（H1–H6）、无序和有序列表、加粗/斜体/删除线、引用块、代码块与高亮、行内代码、链接、表格以及分割线等常用语法。复杂的数学公式或平台专属扩展语法暂不支持。
Q：转换后的 Word 文件安全吗？会上传到服务器吗？
A：完全安全。本工具基于开源项目 VERT，所有转换都在您的浏览器本地完成，.md 源文件和最终生成的 .docx 都不会上传到任何服务器，内容不会被任何人查看或保存。
Q：第一次使用为什么需要等待？
A：首次点击转换时会加载并下载转换引擎组件，这是唯一的一次性操作。之后所有转换都在浏览器中瞬间完成，后续使用秒开、永久免费且不限次数。
