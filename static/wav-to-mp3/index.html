WAV 转 MP3

WAV（Waveform Audio File Format）是微软和 IBM 开发的一种无损音频格式，它几乎保留了录音的原始音质，但文件体积往往非常大——一段几分钟的对话录音就可能达到几十甚至上百 MB，在手机、U 盘和网页中传输都很占用空间。MP3（MPEG-1 Audio Layer III）则是一种有损压缩格式，通过智能去除人耳不易察觉的音频信息，把文件体积压缩到原来的十分之一甚至更小，且音质在大多数场景下依然清晰可辨。MP3 是目前最通用的音频格式，手机、电脑、汽车音响、网页播放器全部支持。

如果你手头有 WAV 音频想更方便地分享、传输或播放，WAV 转 MP3 就是最好的选择。本工具完全在浏览器中完成，无需上传文件到服务器，安全又快速。

常见问题

Q：转换后的 MP3 音质会损失吗？

A：会有少量损失，MP3 是有损格式。建议选择 192kbps 或 320kbps，日常听歌、录音、播客几乎听不出差别；若追求极致体积可用 128kbps。

Q：支持批量转换多个 WAV 文件吗？

A：是的，工具支持一次选择多个 WAV 文件，批量转为 MP3，每个文件独立下载，省时省力。

Q：转换安全吗？我的音频会上传到服务器吗？

A：完全不会。转换在浏览器本地通过 WebAudio API 完成，文件从不离开你的设备，隐私零风险。
